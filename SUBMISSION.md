## Steps to Publish to GitHub
When Git is available on your machine:
```powershell
# 1. Initialize repository
git init

# 2. Stage all project files (secrets in .env and databases are automatically excluded)
git add .

# 3. Create initial commit
git commit -m "Complete StreamFlix streaming application with AI support assistant"

# 4. Set default branch to main
git branch -M main

# 5. Link to your GitHub repository and push
git remote add origin https://github.com/<your-username>/streamflix.git
git push -u origin main
```

## Steps to Deploy on Render (HTTPS)
1. Sign in to [Render](https://render.com).
2. Click **New +** -> **Web Service** -> Connect your GitHub `streamflix` repository.
3. Render will automatically detect the Python environment and `render.yaml` configuration.
4. Set the Build Command:
   ```bash
   pip install -r requirements.txt && python manage.py collectstatic --noinput && python manage.py migrate && python manage.py seed_faqs && python manage.py seed_movies
   ```
5. Set the Start Command:
   ```bash
   gunicorn config.wsgi:application --bind 0.0.0.0:$PORT
   ```
6. Under Environment Variables:
   - `DEBUG`: `False`
   - `SECRET_KEY`: `(Auto-generated by Render or paste a 50+ character string)`
   - `ALLOWED_HOSTS`: `.onrender.com`
   - `SECURE_SSL_REDIRECT`: `True`
   - `SESSION_COOKIE_SECURE`: `True`
   - `CSRF_COOKIE_SECURE`: `True`
   - `MONGO_URI`: `(MongoDB Atlas connection string)`
   - `MONGO_DB_NAME`: `streamflix_prod`
   - `TMDB_API_KEY`: `(Optional TMDB v3 API key; runs seamlessly in curated fallback mode if unset)`
7. Click **Create Web Service**. Render will provision HTTPS automatically.
